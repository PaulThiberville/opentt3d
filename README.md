# OpenTT3D

Refonte graphique 3D d'OpenTTD : le moteur de simulation OpenTTD tourne en
headless dans le navigateur (WebAssembly), le monde est rendu avec Three.js, et
le multijoueur est pair-à-pair (aucun serveur de jeu à maintenir).

**Toute la documentation vit exclusivement dans le
[wiki](https://github.com/PaulThiberville/opentt3d/wiki).** Ce dépôt ne contient
que le code, sa licence et les scripts de build.
